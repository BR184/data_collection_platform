# 文档归档说明

`docs/archive/` 用于保存已经完成的阶段报告、历史调查、旧对比记录和非当前维护范围的审计记录。

归档原则：

1. 当前仍作为规则、契约、runbook、验收依据或近期修复参考的文档保留原路径。
2. 已完成且不再作为当前待办入口的文档移动到归档目录。
3. 归档文档只作历史追溯，不能覆盖 `docs/platform-page-business-rules.md`、当前状态文档和老平台源码中的现行口径。
4. 如果归档文档中的结论重新变成当前任务依据，应先移回合适目录或在当前文档中重新确认后再使用。
