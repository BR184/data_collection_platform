## 文档路由

| 文档 | 唯一职责 | 何时更新 |
|---|---|---|
| `product.md` | 用户、页面范围、六阶段需求、图表和视觉规则 | 页面、交互、展示范围或用户承诺变化 |
| `BI看板数据来源与计算口径核对表.md` | 所有数据字段、来源、计算公式、质量目标和待确认口径 | 用户确认字段、来源或公式变化 |

| `data-contracts.md` | 公式权威的实现约束、CAT 传输、页面 API、状态和下载契约 | 接口、状态、来源一致性或下载契约变化 |
| `architecture.md` | 模块所有权、依赖、构建、运行、安全和旧接口收口 | 技术边界、依赖或关键决策变化 |

涉及 BI 的任务先读本文件和 `progress.md`，再按上表读取对应权威文档。跨领域任务读取所有相关文件，但同一事实只写入一个职责文件；其它文件使用链接，不复制正文。

## 所有权边界

- BI 看板是数据采集平台一级模块，代码和新版文档均由 `D:/projects/data_collection_platform` 维护。
- `D:/projects/bi_dashboard` 已暂停更新。除非用户后续明确恢复，不得对该目录执行任何写入；现有内容只能作为只读迁移证据。
- 所有 BI 数据计算直接遵循 `BI看板数据来源与计算口径核对表.md`；平台通用规则和共享服务仅在与对应编号一致时复用。
- CAT 集成测试接口事实以 `集成测试平台接口使用手册.md` 为来源；手册不覆盖人工确认公式，BI 如何映射和处理缺口以 `data-contracts.md` 为准。
- 平台通用业务规则继续由 `../platform-page-business-rules.md` 维护；公式冲突必须显式报告并由用户确认，不得用通用规则静默覆盖 BI 核对表。
- 平台通用产品、架构和进度文档只保留本入口链接，不展开 BI 专属结论。

## 事实优先级

1. 用户当前明确指令。
2. 数据计算使用 `BI看板数据来源与计算口径核对表.md`。
3. 本目录中其它对应职责的权威文档。
4. 平台通用业务规则、架构决策和已验证代码。
5. 测试与运行结果。
6. 旧 BI 仓库中的迁移证据。

发现文档、代码和运行结果不一致时，先调查根因并统一权威实现与文档，不增加回退、别名或双轨逻辑。
