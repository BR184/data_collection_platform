# 标签组筛选与默认模块范围方案

日期：2026-06-22

## 1. 背景

系统测试缺陷汇总等统计页面当前存在两个容易混淆的问题：

1. 条件筛选里的 `模块名称 = 值` 是文本输入框，用户无法像评审数据管理页面一样在“值”控件里选择已维护的标签组。
2. 新平台事实层展示出了比老平台更多的模块标签。老平台默认只展示一批收口后的模块，新平台如果直接展示全量模块，会让用户感觉与老平台不一致。

这两个问题不能通过硬编码模块名单或按页面临时补丁解决。定版方案如下。

## 2. 标签组使用边界

标签组是按值类型组织的可复用值集合，不是字段集合，也不是字符串输入框的替代品。

1. 只要字段值类型匹配，字段就可以使用同值类型标签组。
2. `STRING` 表示字段值类型是字符串，不表示页面必须渲染成普通文本输入框。
3. `模块`、`模块名称`、`模块名`、`moduleName`、`moduleNames` 在业务上属于同一个模块维度。
4. 字符串标签组可以应用到模块字段、人员字段、状态字段等任意已声明支持标签组的字符串字段。
5. 标签组仍然只能出现在现有条件筛选的“值”控件中，不新增独立标签组筛选区，不新增 `labelGroupFilters` 请求参数。
6. 文本型字段如果声明支持标签组，值控件必须同时支持：
   - 选择同值类型标签组。
   - 输入普通文本值。
7. 标签组条件提交后，后端必须展开为成员值再参与查询、统计、下钻、导出和规则说明。不能只在前端显示可选标签组而后端忽略。

## 3. 默认模块范围方案

新平台事实层保留完整模块数据；页面默认体验通过用户可维护的标签组进行收口。

1. 事实层不删除、不屏蔽、不覆盖额外模块标签。
2. 系统测试统计页默认可应用一个“模块范围标签组”，用于让页面默认展示接近老平台的模块范围。
3. 这个默认范围本质是标签组筛选条件，例如：
   - `模块 包含任意一个 <默认模块范围标签组>`
4. 默认模块范围不能写死在代码里。
5. 默认模块范围的成员不能写死在代码里。
6. 用户或管理员必须可以维护这个标签组成员：
   - 想继续保持老平台体验，就保留老平台模块集合。
   - 想查看更多模块，就把这些模块加入默认模块范围标签组。
   - 想临时排除某些模块，可以通过普通条件筛选或调整标签组完成。
7. “哪个页面 / 哪个字段 / 默认使用哪个标签组”也必须是可配置数据，不是源码常量。
8. 默认标签组筛选仅在用户没有显式设置同字段筛选条件时自动生效；用户显式设置模块条件时，以用户条件为准。
9. 默认筛选必须进入同一套 `filterGroup` 语义，保证页面、下钻、导出、规则说明和接口调用口径一致。
10. 如果默认配置不存在、未启用、标签组被禁用或标签组成员为空，不得把页面筛成空白；应退化为不应用默认模块范围，并在管理侧可排查。

## 4. 建议实现落点

### 4.1 字段元数据

统计板后端字段定义需要返回：

- `labelGroupEnabled`
- `labelGroupValueType`

`moduleName` 等模块字段应声明为 `labelGroupEnabled=true`、`labelGroupValueType=STRING`。

### 4.2 前端条件筛选

`StatisticFilterBuilder` 不能只在 `select` 字段上展示标签组。

支持标签组的文本字段也应使用可搜索值控件，并开启普通文本创建能力，让用户既能选择标签组，也能继续输入普通文本。

### 4.3 后端标签组展开

统计板收到 `valueType=LABEL_GROUP` 的条件后，应统一调用标签组展开服务，得到成员值后再匹配。

展开后仍使用现有集合关系：

- `intersects`
- `notIntersects`
- `containsAll`
- `notContainsAll`

### 4.4 默认筛选配置

建议新增页面默认标签组筛选配置，至少包含：

- 页面或统计板 key。
- 字段 key，例如 `moduleName`。
- 默认标签组 ID。
- 默认操作符，默认 `intersects`。
- 是否启用。
- 备注、创建人、更新时间。

这张配置表只保存默认应用关系，不保存标签组成员。成员继续由 `label_groups` 和 `label_group_members` 维护。

### 4.5 管理入口

默认筛选配置应在管理侧可维护。第一版可以放在标签组设置页的“默认应用”区域，后续再按需要拆成专门页面。

## 5. 验收要点

1. 系统测试缺陷汇总的“模块名称/模块”条件值控件可以选择用户维护的字符串标签组。
2. 同一个字符串标签组可以同时用于评审数据管理的模块字段和系统测试缺陷汇总的模块字段。
3. 文本型字段支持标签组后，仍可输入普通文本值。
4. 默认模块范围不是代码常量，也没有硬编码模块成员。
5. 修改默认模块范围标签组成员后，重新查询页面即可看到默认展示范围变化。
6. 用户显式设置模块筛选条件时，不再叠加默认模块范围。
7. 页面、下钻、导出、规则说明使用同一默认筛选口径。
