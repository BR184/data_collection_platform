# 标签组与对象分群方案废弃记录

日期：2026-06-10

本文档原用于设计“语义标签组 / 业务标签组 / 对象分群”能力。经过业务复盘，该方向对当前标签组诉求的理解存在偏差，相关运行时代码、页面入口、API、服务、测试和数据库迁移已删除。

后续若重新设计筛选保存或业务标签能力，必须重新梳理需求，不得复用本次已废弃的 `business-tag-groups`、`semantic-tag-groups`、`semantic_tag_*`、`segment_*` 运行时模型。

已保留的内容仅包括和老平台规则对齐有关的事实字段归一化、模块识别、下拉选项清洗等改动；这些规则以 `docs/platform-page-business-rules.md` 为准。
