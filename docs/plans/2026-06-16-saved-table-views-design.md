# 固定表格视图方案

## 目标

用户在任意支持筛选的表格页通过关键字、条件筛选、排序、分页和列显示得到目标数据后，可以把当前页面状态固定为一个命名视图，后续一键恢复。

## 设计边界

1. 固定表格视图是用户工作台状态，不是业务事实数据，不改变统计口径、筛选规则、导出规则或老平台对齐规则。
2. 保存内容包括当前路由查询参数；统计看板额外保存列显示、列顺序、分组顺序、宽度策略和当前排序偏好。
3. 固定视图按页面隔离保存，不同页面、不同业务 topic 不混用。
4. 删除固定视图必须弹窗确认，取消删除不能产生错误提示。
5. 第一版使用浏览器本地持久化，和现有统计看板列偏好一致；后续如需多端同步，应单独设计后端用户偏好表，不能混入业务事实层。

## 交互入口

1. 所有支持固定视图的页面统一使用“设置”入口。
2. 统计看板保留原有设置按钮；记录表页在页面动作按钮行增加“设置”，和新增、导入、导出、刷新、规则说明等按钮并列，不放在表格工具栏的独立位置。
3. 设置弹窗中提供“进入页面自动刷新”滑动开关，以及当前页面自己的固定视图列表。
4. 固定视图弹窗中提供命名保存、历史视图列表、应用和删除。
5. 固定视图必须按页面独立存储。客户问题这类同一组件承载多个 topic 的页面，还要把 topic 纳入 scope key，避免互相串用。

## 调查记录

评审数据管理的“模板”按钮已重新确认属于老平台已有能力。新平台已恢复页面入口和 `/api/review-data/template` 接口，浏览器下载文件名与老平台保持为 `模板文件.xls`。该入口只负责下载评审模板，不等同于当前“旧平台列表 Excel 迁移导入”能力；若后续要恢复按模板文件直接导入单个评审报告，需要单独对齐旧平台上传解析链路。
