## 目标与边界

### 用户原始需求
编码页"代码注释率与走查密度趋势"密度轨与"单次人工走查质量分布"散点在重尾数据下主体被压扁；要求直观、可推广到全 BI、不丢事实。另答疑：注释率折线断开 = 当天无合法注释率观测（并集周期 + `connectNulls: false` 的诚实表达），非缺陷，不改。

### 可验证的成功标准
1. 重尾fixture（密集个位数主体 + 连续中档尾 + 极端值）下主体刻度均匀可读（0/5/10/15/20 型），尾部压缩进单段锯齿带，带顶标签=真实极大值；
2. 均匀分布/有界百分比/小样本序列不产生无意义断轴，刻度与旧行为等价；
3. 前端全量 vitest、lint、`vite build` 全绿；受影响契约测试同步更新；
4. 词条补充断轴含义说明（领导可自助理解）。

### 明确禁止（红线）
- 不逐图硬编码阈值（屎山）；只改唯一轴工具，图表类零逻辑改动（仅 spread 消费）。
- 不引入对数轴/双轨兼容层；不隐藏离群点（断带内仍绘制，tooltip/导出保留真值）。
- 不改后端、不改黄金基线（纯前端视觉层）。

## 约束与背景

- ECharts 6.1.0 原生 `AxisBreak`：`breaks:[{start,end,gap}]` 把 [start,end] 压缩为固定锯齿带，带内数据仍映射绘制；轴 `interval` 在外部空间生刻度、落入断区者自动移除。
- 消费方 6 条值轴：`QualityTrendSmallMultiplesChart`（注释率/密度双轨）、`ReviewQualityScatterChart`（X/Y）、`ReviewQualityDualPanelChart`（X/X）。
- 有界域（0–100%、整数计数）图表不接自适应轴，不受影响。

## 证据与根因

- 旧 `buildBreaks`：gap ≥ 全距 18% 且 ≥ 4×中位间隔才断 → 连续尾切不动；主体上界=首个显著间隔下界，被中档值顶高 → 主体压扁；锯齿带边界产生 139.685 类难读刻度。
- 注释率断点成因（前端 `CodingStageContent.vue` L205-213）：周期=两序列并集，缺合法观测日为 null 且 `connectNulls:false`；内网注释率覆盖 2425/2634、密度覆盖 2585/2634 → 断点分布与覆盖率吻合。

## 方案与步骤

1. 重写 `adaptive-value-axis.ts`（替换式，删旧间隔启发式）：
   - 主体目标 = max(minimumMax, min(P95_floor, 4×中位数))；主体步长 = nice(主体目标/splitNumber)；主体上界 = 步长×splitNumber；
   - 观测极大值 > 主体上界×1.25 → 单段断轴 [主体上界, 观测极大值]，`max`=观测极大值（带顶标签=真实极值）；否则无断轴、`max`=nice(观测极大值)、interval=max/splitNumber；
   - 返回 `{min:0, max, interval, breaks, breakArea?}`（删除 splitNumber 字段，契约测试同步）。
2. 更新 `adaptive-value-axis.test.ts`（空/均匀/重尾连续/去重/小样本五类）与 `chart-contract.test.ts` 断言（splitNumber→interval；断轴存在性保留）。
3. 词条 `chart-explanations.ts`：质量趋势与走查散点词条追加"极值时轴自动断轴：锯齿带为极值区压缩展示，悬停/导出为真实值；折线断开=当日无合法观测"。
4. 验证：定向 vitest → 全量 vitest/lint/build → 门禁 → 浏览器 18181 实测两图（用户本地已拉起）。
5. 文档：`docs/bi-dashboard/progress.md` 追加条目；本计划收尾更新状态。

## 决策记录

| 编号 | 事项 | 结论 | 理由/否决 |
|---|---|---|---|
| E1 | 轴策略 | 百分位主体+单段尾断轴 | 领导要直观：主体均匀刻度+锯齿带是报表惯例；否决对数轴（0 值与达标带直觉被破坏）、否决值轴缩放条（首屏仍扁）、否决逐图阈值（屎山） |
| E2 | 主体上界 | min(P95_floor, 4×中位数) 且 ≥ minimumMax | P95 在大样本稳健、小样本退化为次大值仍安全；4×中位数上限防稀疏中档顶高主体；minimumMax 保住达标带可见 |
| E3 | 断点（折线断开） | 不改 | 诚实表达"当日无合法观测"，连接即伪造连续性 |

## 接口契约

- `buildAdaptiveValueAxis(values, {minimumMax, splitNumber?}) → {min:0, max, interval, breaks, breakArea?}`；图表类 spread 消费，无新增 prop。

## 风险与假设

- 假设 ECharts `interval` 与 breaks 共存时断区内刻度自动移除（类型注释 'auto' 语义）；若实测残留再收敛。
- 风险：4×中位数上限在"双峰合法分布"下可能过度压缩第二峰——由 1.25 触发因子兜底（第二峰 ≤ 主体×1.25 时不断轴）。
