- SQLState42类不是瞬态重试错误；首图0/3与非瞬态失败直接终态相符。该机制不能通过重试修复程序类型错误；后续成功的相关镜像运行才可使依赖重新就绪，因此停止自动同步不等于解除已有BLOCKED。
