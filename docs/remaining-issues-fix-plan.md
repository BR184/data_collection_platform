## 已完成

### 问题1：下钻表格滚动条

- 状态：已修复。

- 状态：已完成契约落地。

SELECT
  issue_iid,
  title,
  project_id,
  module_names,
  severity_level,
  testing_phase,
  system_test_label,
  is_excluded,
